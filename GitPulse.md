# GitPulse — карта домена

Модуль git-аналитики, встраиваемый в FastAPI-хост, который показывает активность
репозитория: ветки, коммиты, авторов, долю вклада и активность.

## Модули

| Модуль | Ответственность |
|--------|-----------------|
| `core` | Доменные модели. Без ввода-вывода и без фреймворка. |
| `git` | Запуск git CLI: только argv, таймауты, лимиты вывода. |
| `analytics` | Расчёт доли вклада и корзин активности. |
| `fastapi_app` | REST-маршруты и упакованный UI. |

## Границы

- `core` не импортирует `git`, `analytics`, `fastapi_app` и FastAPI.
- `git` и `analytics` не импортируют `fastapi_app` и FastAPI.

Границы зафиксированы в `pyproject.toml` и проверяются командой `make test`.

## Публичный API

Хост-приложения зависят от трёх точек входа:

- `create_router`
- `create_app`
- `mount_static_ui`
